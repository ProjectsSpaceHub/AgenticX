## Overview

Agentic X is a Python-based Multi-Agent System (MAS) designed to support intelligent decision-making during unexpected event crises.

By combining **Large Language Models (LLMs), rule-based reasoning, and multi-agent negotiation**, the system enables specialized agents to evaluate alternative solutions, communicate their decisions, and resolve conflicting priorities through coordinated negotiation.

## Our Solution

Event management involves competing priorities. A creative solution may exceed the budget, an affordable alternative may compromise safety, and a promising proposal may lack the resources required for execution.

**Agentic X brings these perspectives together.**

Four specialized agents independently evaluate proposed solutions. When disagreements arise, the coordinator explores alternative proposals through up to three negotiation rounds. If no feasible agreement is reached, the case is escalated for human review.

## Our Agents

| Agent | Type | Responsibility |
|---|---|---|
| **Creative** | LLM-Based | Evaluates creative quality and event presentation. |
| **Finance** | Rule-Based | Validates costs, savings, and budget constraints. |
| **Safety** | Rule-Based | Verifies safety conditions, permits, and risk limits. |
| **Operations** | Hybrid (LLM + Rules) | Evaluates operational feasibility, staffing, time, and resources. |

## Dataset

The project uses a synthetic dataset containing **150 crisis scenarios and 450 candidate solutions**, covering three categories:

- **Screen Failure**
- **Budget Overrun**
- **Safety Conflict**

Each scenario includes environmental conditions, available resources, and alternative proposals for multi-agent evaluation.

## Communication Protocol

Agentic X implements an **ACL-like communication protocol** to coordinate interactions between agents.

`CFP` · `PROPOSE` · `REQUEST` · `INFORM` · `ACCEPT` · `REFUSE`

The coordinator proposes solutions, collects independent evaluations, identifies objections, and manages negotiation across a maximum of three rounds.

A proposal is accepted when all four agents approve it and the execution deadline condition is satisfied. Otherwise, the system evaluates another available alternative or escalates the unresolved case.

## Interactive Website

The interactive website allows users to:

- Select event-crisis scenarios.
- Adjust budget, time, and equipment availability.
- Run multi-agent evaluations and negotiations.
- Explore individual agent decisions and explanations.
- Review negotiation rounds and ACL communication logs.
- View final agreements and escalations.

The interface presents results generated by the real Python multi-agent backend.

## LLM & LangSmith Integration

Agentic X integrates **LLMs** for context-aware decision-making and **LangSmith** for system observability.

LangSmith supports:

- Agent-level and negotiation tracing.
- LLM execution monitoring.
- Execution latency measurements.
- Evaluation feedback and decision records.

## Testing & Evaluation

Agentic X is evaluated through three primary event-crisis scenarios, agent-level assessments, multi-round negotiation, and ACL communication validation.

The project includes automated tests, controlled conflict scenarios, and LangSmith execution traces to support evaluation of system behavior.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/ProjectsSpaceHub/AgenticX.git
cd AgenticX
```

### 2. Install Dependencies

Python 3.10 or later is recommended.

```bash
python -m pip install -r requirements.txt
```

### 3. Get Your API Keys

**Gemini API Key — Required for LLM Evaluation**

[Get your Gemini API Key](https://aistudio.google.com/api-keys)

**LangSmith API Key — For Tracing and Monitoring**

[Get your LangSmith API Key](https://smith.langchain.com/)

After generating your keys, configure the following environment variables:

```text
GOOGLE_API_KEY=your_gemini_api_key
AGENTICX_MODEL=gemini-3.5-flash-lite

LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_langsmith_api_key
LANGSMITH_PROJECT=AgenticX-Studio67-Final
```

Set these variables in your execution environment before starting the application. LangSmith credentials are optional for basic execution but required for remote tracing.

**Important:** Never commit real API keys to GitHub.

### 4. Run the Application

From the project root, run:

```bash
python -m uvicorn integration_api:app --host 127.0.0.1 --port 8000
```

Open your browser at:

**http://127.0.0.1:8000**

### 5. Run Automated Tests

```bash
python -m pytest tests -v
```

Additional experiments and evaluation evidence are available in the five Jupyter notebooks.
